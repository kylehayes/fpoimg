How to Use

URL Pattern

Generate placeholder images by using a simple URL pattern:

https://fpoimg.com/{width}x{height}?text={caption}&bg_color={bg_color}&text_color={text_color}

Basic Usage
https://fpoimg.com/800x600

Creates an 800×600 pixel image with default colors.

With a caption
https://fpoimg.com/800x600?text=Caption

Creates an 800×600 pixel image with a caption

Custom Colors
https://fpoimg.com/400x300?bg_color=4361ee&text_color=ffffff

Creates a 400×300 pixel image with blue background and white text.

Square Image
https://fpoimg.com/500

Creates a 500×500 pixel square image.

Gradient Background
https://fpoimg.com/800x600?gradient=sunset&text_color=ffffff

Creates an 800×600 image with a sunset gradient and white text.

Custom Gradient
https://fpoimg.com/400x300?gradient=FF5733,3357FF&gradient_angle=45

Creates a 400×300 image with a custom two-color gradient at 45°.

Named Colors
https://fpoimg.com/400x300/tomato/white

Use CSS color names instead of hex codes — in the URL path or as query params.

Named Colors (Query Params)
https://fpoimg.com/400x300?bg_color=steelblue&text_color=white

Works with bg_color, text_color, and even gradients.

Multiline Text
https://fpoimg.com/400x300?text=Line+1\nLine+2

Use \n for line breaks. Long text auto-wraps to fit the image.

Hide Dimensions
https://fpoimg.com/800x600?dims=false

Hide the dimension label for a clean placeholder. Captions still render if provided.
